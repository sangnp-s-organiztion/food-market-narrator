# Yêu cầu tính năng dành cho Người bán

## 1. Quản lý nội dung POI

Người bán có thể tạo và quản lý Điểm quan tâm (POI).

### Thông tin POI

Mỗi POI phải bao gồm:

- Tên
- Mô tả văn bản
- Hình ảnh
- Vị trí trên bản đồ (vĩ độ / kinh độ)
- Bán kính kích hoạt
- File audio thuyết minh HOẶC kịch bản TTS
- Mức ưu tiên

---

# 2. Tải lên media

Người bán có thể tải lên các file media liên kết với POI.

### Media được hỗ trợ

- Hình ảnh
- Audio thuyết minh

### Yêu cầu

- Tải lên nhiều hình ảnh.
- Tải lên file audio thuyết minh.
- Thay thế hoặc cập nhật media hiện có.

---

# 3. Tạo mã QR

Người bán có thể tạo mã QR cho POI.

### Trường hợp sử dụng

- Tài liệu in ấn
- Trạm xe buýt
- Điểm tham quan du lịch

### Tính năng

- Tạo mã QR liên kết với POI.
- Tải xuống hình ảnh mã QR.
- In mã QR.

---

# 4. Chỉnh sửa nội dung POI

Người bán phải có khả năng cập nhật thông tin POI.

### Trường có thể chỉnh sửa

- Mô tả
- Hình ảnh
- Audio thuyết minh
- Kịch bản TTS
- Bán kính kích hoạt

---

# 5. Phân tích cơ bản

Người bán có thể xem hiệu suất của các POI.

### Dữ liệu phân tích

- Số lần phát thuyết minh
- POI phổ biến
- Thời gian nghe trung bình

---

# 6. Bảng điều khiển quản lý nội dung

Cung cấp bảng điều khiển để quản lý POI.

### Tính năng

- Liệt kê tất cả POI
- Tìm kiếm POI
- Chỉnh sửa POI
- Xóa POI
