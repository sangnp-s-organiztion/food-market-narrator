# Docs Index

Thư mục `docs/` được tổ chức theo nhóm tài liệu để dễ tìm, dễ mở rộng và dễ review.

## Cấu trúc chính

- `architecture/`: Tài liệu kiến trúc và endpoint tổng quan.
- `api/`: Tài liệu API backend, endpoint và dữ liệu.
- `setup/`: Hướng dẫn môi trường local và biến môi trường.
- `features/`: PRD và tài liệu yêu cầu tính năng theo vai trò.
- `mobile/`: Tài liệu kỹ thuật MAUI app.
- `admin/`: Tài liệu web admin.
- `saler/`: Tài liệu web saler.
- `testing/`: Chiến lược test và test case.
- `runbook/`: Vận hành và troubleshooting.
- `decisions/`: Ghi chú quyết định kỹ thuật (ADR light).
- `changelog/`: Ghi chú phiên bản.
