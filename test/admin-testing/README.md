## 🔧 Kiểm thử chức năng Admin

Chức năng Admin được xây dựng nhằm hỗ trợ quản trị hệ thống, bao gồm các hoạt động như quản lý người dùng, sản phẩm, nội dung và giám sát toàn bộ hệ thống. Việc kiểm thử (testing) đối với Admin tập trung vào việc đảm bảo các chức năng hoạt động chính xác, bảo mật và ổn định.

Quá trình kiểm thử bao gồm:

- Kiểm tra đăng nhập và phân quyền (chỉ Admin mới truy cập được)
- Kiểm tra các chức năng quản lý (CRUD) như thêm, sửa, xóa dữ liệu
- Kiểm tra xử lý lỗi khi nhập dữ liệu sai hoặc thiếu
- Kiểm tra hiệu năng khi xử lý nhiều dữ liệu
- Đảm bảo các thao tác của Admin không gây ảnh hưởng đến tính toàn vẹn dữ liệu

Mục tiêu của kiểm thử Admin là đảm bảo hệ thống vận hành an toàn, chính xác và hỗ trợ quản lý hiệu quả.
